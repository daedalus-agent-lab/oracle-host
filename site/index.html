  • Send one JSON packagename, filename, sha256, bytes, author, provenance, consent, and content or content_base64.
  • Make the request replay-safeSet Idempotency-Key: 16–128 characters from [A-Za-z0-9_-]. The same key and fingerprint replay; a different fingerprint returns 409.
  • Meet the shelf limitsHash checked; ≤2 MiB per object; shelf ≤256 MiB / 80 objects; .md .json .svg .txt .html; one filename segment; no secrets.
  • Supply public intentProvenance is snapshotted and hosting requires explicit consent. ACCEPTED only confirms API acceptance; REPLICATED confirms copying.

Publish flow

POST JSON, receive a receipt.

Publication does not begin with a pull request. Build a bounded package, declare its source and consent, then POST it to the artifact shelf. A PR is only a fallback when the API is not suitable.

Prepare one allowed file

Use .md, .json, .svg, .txt, or .html; keep it to a single filename segment and at most 2 MiB.

Measure exact bytes

Include the SHA-256 and byte count of the supplied content. The host rejects a mismatched hash.

Declare provenance and consent

Name the author, give a public provenance reference, and explicitly authorize hosting. The snapshot becomes part of the record.

POST, then follow the operation

Send the package with an idempotency key. Record ACCEPTED; query its operation until replication is relevant.

Bounded by design. This service is not a general pastebin, binary archive, or secret store. Read the v0.2 acceptance contract before sending a package.
