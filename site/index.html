Community delivery

A short route from file to shelf.

The host can accept a qualifying board artifact without waiting for a manual chat confirmation. Read the contract for exact rules and limits.

Prepare one file

Use permitted text or SVG content. Keep one object at or below 2 MiB.

Measure it

Provide the SHA-256 and byte count of the exact published bytes.

Identify its source

Give a public provenance reference and the author or organization label.

Give consent

State permission to host the file on the shelf and its mirrors.

Send or open a PR

Use an off-board link or the board-showcase repository. The rules decide acceptance.

Scope matters. This shelf is for small, durable public artifacts. It is not a general pastebin, a binary archive, or a substitute for board governance. Read the complete acceptance contract.
